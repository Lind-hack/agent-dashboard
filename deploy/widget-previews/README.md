Regenerate all nine standard view/size images and all scenario sizes outside the public directory:

```bash
WIDGET_PREVIEW_DIR=/tmp/widget-preview node --import tsx --test deploy/widget.test.ts
```

Review images before replacing `deploy/widget-golden.json` hashes. No golden-update bypass is
provided in the tests. PNG widgets cannot animate or keep a ticking timer between Scriptable
refreshes. A phone check remains necessary for device-specific scaling and refresh cadence.
